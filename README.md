# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search, and delete notes. Users can assign each note to a Personal, Work, or Study category, while the application validates note length and saves notes in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add new notes
- Organize notes by Personal, Work, or Study
- Display the date and time when each note was created
- Delete individual notes
- Search notes by text
- Case-insensitive search
- Validation for empty notes
- Validation for notes over 200 characters
- Display the correct number of notes
- Save notes using localStorage
- Load notes automatically after refreshing the page
- Responsive design for smaller screens
